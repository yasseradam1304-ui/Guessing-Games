Both games require Python 3 with Tkinter. Tkinter is included with most
standard Python installations, so no additional package is usually needed.

The Hangman game can use a UTF-8 "words.txt" word list placed next to the game
script, or a .txt / Hunspell .dic dictionary selected in the game. The older
"dictionnaire.txt" filename is also supported. An Internet connection is not
required.
